📚 Library Management System

📖 About the Project

The Library Management System is a simple and user-friendly project developed using the C Programming Language. The project is designed to manage library book records and demonstrate the practical application of basic programming concepts.

This project was developed as part of the Bachelor of Computer Applications (BCA) academic coursework.

✨ Features

- 📘 Manage library book records
- ➕ Add book details
- 📋 Display book information
- 🖥️ Simple menu-driven interface
- 💻 Easy to understand and use

🛠️ Technologies Used

- Programming Language: C
- Compiler: GCC or any compatible C compiler
- Concepts: Variables, conditional statements, loops, and functions (where implemented)

📂 Project Structure

Library-Management-System/
│
├── library.c
└── README.md

🚀 How to Run the Project

1. Download or clone this repository.

2. Open the project folder in your computer.

3. Compile the C source file using GCC:
   
   gcc library.c -o library

4. Run the program.
   
   Windows:
   
   library.exe
   
   Linux/macOS:
   
   ./library

🎯 Project Objective

The main objective of this project is to understand the fundamentals of C programming and develop a basic application for managing library book information.
